jlog

A small, fast, read-only pager for JSON Lines logs, in the terminal or a local browser tab. One native executable, no runtime.

Install v0.1.0

Linux and macOS:

curl -fsSL https://jlog.logging.work/install.sh | sh

The script downloads the archive for your system, checks its SHA-256 against SHA256SUMS and installs jlog into ~/.local/bin (override with JLOG_INSTALL_DIR). Or download an archive yourself:

Quick start

jlog app.jsonl                  # open a log file
kubectl logs deploy/api | jlog  # page piped logs
jlog --web app.jsonl            # browse in a local 127.0.0.1-only web page
jlog --manual                   # full offline manual

jlog

A small, fast, read-only pager for JSON Lines logs, in the terminal or a local browser tab. One native executable, no runtime.

Install v0.2.1

Linux and macOS:

curl -fsSL https://jlog.logging.work/install.sh | sh

The script downloads the archive for your system, checks its SHA-256 against SHA256SUMS and installs jlog into ~/.local/bin (override with JLOG_INSTALL_DIR) and its man page into ~/.local/share/man/man1. Or download an archive yourself:

Minimal variant

The same viewer without jlog send / jlog receive (peer-to-peer transfer). It makes no network connections at all; the optional --web page is served on 127.0.0.1 only. For environments that do not allow networking tools:

curl -fsSL https://jlog.logging.work/install.sh | sh -s -- --minimal

Quick start

jlog app.jsonl                  # open a log file
kubectl logs deploy/api | jlog  # page piped logs
jlog --web app.jsonl            # browse in a local 127.0.0.1-only web page
jlog send app.jsonl             # hand a log to someone: prints a ticket
jlog receive jlog1...           # ... which they open with this
jlog man                        # manual page (jlog manual: plain text)
